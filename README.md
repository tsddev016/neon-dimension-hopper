# Neon Dimension Hopper

Jogo 2D de Bunny Hop + alternância de perspectiva (estilo Toodee & Topdee).

## Como jogar

Abra o arquivo `index.html` no navegador ou acesse o deploy na Vercel.

### Controles
- **WASD / Setas** → Mover
- **Espaço** → Pular (modo Side-Scroller)
- **Shift / Tab** → Alternar perspectiva (Side ↔ Top-Down)
- **R** → Reiniciar

### Mecânicas
- **Bunny Hop**: Pule exatamente no momento do pouso para preservar e aumentar velocidade.
- **Air Strafe**: Mude de direção no ar para ganhar impulso extra.
- **Fricção**: Se demorar para pular após pousar, perde momentum.

Feito com HTML5 Canvas puro (sem dependências).
